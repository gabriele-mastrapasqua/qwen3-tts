# Text bank v2 for the serving benchmarks — English + Italian, neutral register.
#
# bank-version: v2
# bank-sha256:  55b286369ef8dd44
#
# WHY A VERSION. A benchmark number belongs to the corpus that produced it. The v1 bank held
# 21 texts in total, and 3 of them carried the whole `long` class -- in a 30-minute soak each
# of those was spoken roughly 216 times. Repetition that heavy does not trip an engine cache
# (the prefix cache is keyed on speaker and language, not on text), but it does something
# quietly worse: it removes text variability from the measurement, so the spread is narrower
# than reality and a regression that only shows on unusual lengths is invisible.
#
# So v2 is an ERA BOUNDARY, in the same sense as the v2 serving work: numbers measured on v1
# and numbers measured on v2 are NOT comparable, and every artifact records which bank it used.
# v1 is kept at tests/load_texts_en.txt -- nothing was deleted, and the v1 texts are all here
# too, so the classes are extended rather than redefined.
#
# WHY THE CLASS BANDS ARE UNCHANGED. Each class keeps the character band it had in v1, measured
# rather than asserted:
#
#   short            65 texts,  21- 27 ch (~1.5-1.9 s)
#   medium          126 texts,  62- 72 ch (~4.4-5.1 s)
#   conversational   49 texts,  43- 78 ch (~3.1-5.6 s)
#   long             33 texts, 317-361 ch (~22.6-25.8 s)
#   italian           4 texts,  22-315 ch (~1.6-22.5 s)
#
# Redefining a class -- making `short` mean 70 characters instead of 25 -- would silently break
# comparability with every registered profile. Extending within the band does not.
#
# Format:  <class>\t<text>
# Classes: short | medium | long | conversational | italian
#
# WHICH CLASS FOR WHICH RUN. `medium` is the workhorse of the fast screen: at ~4-5 s of audio a
# request produces enough chunks to exercise the streaming path while still allowing a high
# request rate, which is what gets the sample count up. `short` at ~1.5 s yields too few chunks
# for the cadence metrics to see anything. The 30-minute qualification uses the stratified mix.
